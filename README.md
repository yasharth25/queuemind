# QueueMind

QueueMind is a prototype for anonymous queue simulation, demand forecasting and person-only queue analytics. **Synthetic data is not real NIT Rourkela operational data.**

## Privacy and responsible deployment

QueueMind does not implement face recognition, biometric recognition, student identification, or identity databases. Temporary tracker IDs are anonymous. Raw/processed video retention is disabled by default. Any campus CCTV deployment requires institutional authorization, camera calibration, and compliance with campus privacy policy; aggregate queue statistics are preferred to raw-video storage.
